# 应用界面导航（2026-10-27）

本地入口：<http://127.0.0.1:5173/>。左侧或手机顶部为功能页面导航，每次只显示当前页面；浏览器后退、前进和 `#experiments` 等深链接可用。切换页面保留输入草稿和房间选择，不会自动开启或停止后台控制。

| 页面 | 用来做什么 | 数据来源 |
| --- | --- | --- |
| 住宅总览 | 查看九空间户型、当前所在房间与环境摘要；可切换2D/3D | 原生活模拟 |
| 设备控制 | 独立选择要控制的房间，调节已有设备；天气/时间在折叠设置中 | 原生活模拟 |
| 家庭助手 | 输入指令，查看理解需求、拟定动作、检查风险、执行反馈；展开详情检查完整轨迹 | 当前配置的语义模式，本轮验证为mock |
| 自动运行 | 管理后台自动控制、偏好和生活推演；未运行时不显示虚假的零收益 | 原生活模拟，生活推演需已验证真实模型 |
| 物理实验 | 新建全屋实验、查看实验结果、检查空间与假设 | 独立EnergyPlus九热区，非首页实时状态 |
| 状态与趋势 | 查看全屋遥测、模拟电量与变化记录 | 原生活模拟 |

物理实验内有三个视图：“新建实验”填写必要的控制方式、场景、占用房间和目标；“实验结果”选择运行记录、查看九空间结果与时序；“空间与假设”查看热区、未校准边界和灯具数据录入。创建成功后自动切换结果视图，原始JSON/SQL等复现文件收在下载详情中。

颜色：雾蓝灰画布、白色内容区、钴蓝导航/操作；首页以共享户型作为主视觉。技术标识保留在需要审计的位置，不混入主要操作流程。普通生活模拟与EnergyPlus使用不同数据来源标识，不能把它们的数字直接视作同一场运行。

验证：Vitest 15项、Playwright 12项、TypeScript/Vite与bundle预算通过；Edge桌面1440×1000、手机390×844的六页面截图位于 `output/ui-workspace-<page>-desktop.png` 与 `-mobile.png`。测试覆盖页面隔离、草稿保留、后退、2D/3D、控制与助手、自动运行、真实EnergyPlus作业、结果切换和下载。六页面手机无横向溢出，WCAG A/AA自动检查通过；不等同真实用户可用性研究或用户审美认可。
